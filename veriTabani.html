SQL Playground

Aşağıdaki editör gerçek bir SQLite veritabanına bağlı — tarayıcında çalışır, sunucu gerekmez. Notlardaki örneklerin yanında ▶ Çalıştır butonuna bastığında kod otomatik olarak buraya yüklenip çalışır. İstersen kendi sorgunu da yazıp deneyebilirsin.

Not: Bu playground SQLite motoru kullanır. Notlardaki bazı komutlar (DECLARE, PRINT, CREATE PROCEDURE, CREATE FUNCTION, EXEC sp_rename gibi) SQL Server'a özgüdür ve SQLite'ta çalışmaz — bu farkı önemli bulduğum için gizlemedim. Böyle örnekler SQL Server (T-SQL) etiketiyle işaretli, çalıştır butonu yok.

01

DDL — Veri Tanımlama Dili

Veri tabanını oluşturma, yapısını tanımlama, yapısını değiştirme ve silme işlemlerini içerir.
Komutlar: CREATEALTERDROPTRUNCATE

1. CREATE Komutu

Veri tabanı veya tablo oluşturmada kullanılır.

Create ile Veri Tabanı Oluşturma

SQLTarayıcıda uygulanamaz
CREATE DATABASE Siparisler;

Create ile Tablo Oluşturma

SQL
CREATE TABLE Ürünler (
    ürünID int Primary Key,
    ürünAd int,
    ürünAdet int,
);

Playground'da tablo adı çakışmasın diye OrnekUrunler ile deneyebilirsin — mantık birebir aynı.

2. ALTER Komutu

Mevcut bir tablo üzerinde değişiklikler yapmak için kullanılır. Tabloya sütun eklenebilir, var olan sütun değiştirilebilir veya silinebilir.

Alter ile Tabloya Sütun Ekleme

SQL
ALTER TABLE Ürünler ADD eklenecekSütun int;

Alter ve Drop ile Tablodan Sütun Kaldırma

SQL
ALTER TABLE Ürünler DROP COLUMN silinecekSütun;

Alter ile Sütunun Veri Tipini Değiştirme

SQLSQL Server (T-SQL)
ALTER TABLE Ürünler ALTER COLUMN değişecekSütun int;

SQLite'ta doğrudan sütun tipi değiştirme komutu yoktur; genelde yeni sütun ekleyip veriyi taşıma yoluna gidilir.

Alter ile Sütun Adını Değiştirme

SQLSQL Server (T-SQL)
EXEC sp_rename 'Ürünler.eskiSütun', 'yeniSütun', 'COLUMN';

Alter ile Tablo İsmini Değiştirme

SQLSQL Server (T-SQL)
EXEC sp_rename 'Ürünler', 'NewÜrünler';

3. DROP Komutu

Veritabanı veya tablo silme komutudur.

Drop ile Veritabanını Silme

SQLTarayıcıda uygulanamaz
DROP DATABASE Siparisler;

Drop ile Tablo Silme

SQL
DROP TABLE Ürünler;

Alter ve Drop ile Tablodan Sütun Silme

SQL
ALTER TABLE Ürünler DROP COLUMN silinecekSütun;

4. TRUNCATE Komutu

Truncate ile Tablodaki Verileri Silme

SQLSQL Server (T-SQL)
TRUNCATE table Ürünler;

SQLite'ta TRUNCATE komutu yoktur; aynı işi DELETE FROM tabloAdı; yapar (tabloyu değil, içindeki verileri siler).

02

DML — SELECT Komutu

DML (Data Manipulation Language): Veritabanındaki verileri sorgulamak, getirmek, düzenlemek ve özetlemek için kullanılır. En sık kullanılan komutlar: SELECTINSERTDELETEUPDATE

Tek tablo içinde çeşitli kriterlere göre sorgulama, sıralama, özetleme ve ortalama gibi işlemler yapmak için kullanılır. Gerekli bilgileri öne çıkarmak amacıyla kullanılır.

Tablodaki tüm verileri getirir

SQL
SELECT * FROM Ürünler;

Ürünler tablosundan ürün adlarını getirir

SQL
SELECT ürünAd FROM Ürünler;

Birden fazla sütun getirme. Müşteriler tablosundan müşteri ad ve soyadları getirir

SQL
SELECT müsteriAD , müsteriSoyad FROM Müsteriler;

DISTINCT Komutu

Aynı olanlardan sadece birini getirir. Müsteriler tablosunda şehir sütununda iki tane "İstanbul" varsa sadece bir tanesini gösterir.

SQL
SELECT DISTINCT sehir FROM Müsteriler;

WHERE İfadesi

Koşula göre veri getirme

SQL
SELECT * FROM Ögrenciler WHERE vizeNotu > 60;
-- Öğrencilerin kayıtlarından vize notu 60'tan büyük olanları getirir.

SELECT * FROM Ögrenciler WHERE ögrenciAd = 'Umut';
-- Öğrencilerden adı Umut olanları getirir.

AND İfadesi

Birden fazla koşul sağlandığında

SQL
SELECT * FROM Ögrenciler WHERE vizeNotu > 60 AND ögrenciAd = 'Umut';
-- Öğrencilerden vize notu 60'tan büyük ve ismi Umut olanları getirir.

OR İfadesi

SQL
SELECT * FROM Ögrenciler WHERE vizeNotu > 60 OR ögrenciAd = 'Umut';
-- Öğrencilerden vize notu 60'tan büyük olanları veya ismi Umut olanları getirir

BETWEEN İfadesi

İki değer arası

SQL
SELECT * FROM tabloAdı WHERE sütunAdı1 BETWEEN 10 AND 15;
-- 10 ile 15 arasındaki değerleri getirir (10 ve 15 dahil).

NOT İfadesi

Koşulun tersi

SQL
SELECT * FROM Ögrenciler WHERE NOT ögrenciAd = 'Umut'
-- Ögrencilerden ismi "Umut" olmayanları getirir.

LIKE İfadesi

Karakter türü verilerde arama

SQL
SELECT * FROM Ögrenciler WHERE ögrenciAd LIKE 'U%'
-- U harfiyle başlayan ögrencileri getirir.

SELECT * FROM Ögrenciler WHERE ögrenciAd LIKE '%UMU%'
-- İçinde UMU geçen öğrenci kayıtlarını getirir.

SELECT * FROM Ögrenciler WHERE ögrenciAd NOT LIKE '%U%'
-- İçinde U harfi geçmeyen Ögrenci kayıtlarını getirir

IN, NOT IN İfadesi

Belirli bir küme içinde arama (OR gibidir aslında)

SQL
SELECT * FROM tabloAdı WHERE sütunAdı IN (7, 12)
-- Değeri 7 veya 12 olan kayıtları getirir.

SELECT * FROM Ögrenciler WHERE ögrenciAd IN ('Umut', 'Zeynep', 'Mehmet') OR ögrenciAd LIKE 'A%'
-- Adı Umut, Zeynep, Mehmet olanları veya Adı A ile başlayanları getirir

SELECT * FROM Ögrenciler WHERE ögrenciAd NOT IN ('Umut')
-- Öğrencilerden adı Umut olmayanları getirir

ORDER BY Komutu

Sıralama

SQL
SELECT * FROM Ürünler ORDER BY stok_miktari
-- Stok sayısı küçükten büyüğe sıralanır

SELECT * FROM Müsteriler WHERE müsteriID>5 AND müsteriID<9 ORDER BY müsteriAd
-- Müsteri ID'si 6 7 8 olanların isimlerini alfabetik sıralar

-- ASC → Artan sırada (varsayılan)
-- DESC → Azalan sırada
-- Örnek: OgrAd, OgrID desc denirse eğer, burada Adlar alfabetik sıralanır
-- aynı isimde olanların ise ID'si büyükten küçüğe sıralanır.

AS Komutu

Geçici Sütun

SQL
SELECT (Vize+Final)/2 AS 'Ortalama' FROM Notlar
-- Vize Final notlarının ortalamasını alıp geçici oluşturulan Ortalama sütununda gösterir.

SELECT Vize , Vize+5 AS '+5 Eklenmiş Hali' FROM Notlar
-- Vize notlarının normalini bir de +5 eklediğimiz +5 Eklenmiş Hali sütununu gösterir.

GROUP BY - COUNT Komutu

SQL
SELECT kitapTür, COUNT(kitapAdi) AS 'Kitap Sayisi' FROM Kitaplar GROUP BY kitapTür
-- Kitapların türlerinden kaç tane var bulur ve bunu Kitap Sayisi sütununda tutar.

SELECT kitapAdi, COUNT(kitapAdi) AS 'Kitap Sayısı' FROM Kitaplar GROUP BY kitapAdi
-- Kitapların adlarına göre kaç tane olduğunu bulur ve bunu Kitap Sayisi sütununda tutar.

SELECT departmanAdi , COUNT (departmanID) FROM Departmanlar GROUP BY departmanAdi
-- Departman Adı aynı olanları gruplandırır ve bunların sayısını alır.

SELECT COUNT(kitapAdi) FROM Kitaplar WHERE Fiyat>45,
-- Kitapların fiyatının 45 üzeri olanların sayısını getirir.

SELECT COUNT(DISTINCT kitapFiyat) FROM Kitaplar;
-- Kitapların fiyatlarından aynı olanları çıkarır da öyle sayar.

SELECT ürünKategori , COUNT(*) AS 'Ürünlerin Sayısı' FROM Ürünler GROUP BY ürünKategori
-- Ürünün kategorisi ve adeti görünür ekranda.

SELECT COUNT(*) AS 'Ürünlerin Sayısı' FROM Ürünler GROUP BY ürünKategori
-- Burada ürünün kategorilere ayrılır ama sadece bunun sayısı gösterilir. 2 2 3 gibi mesela.
-- Ama 2 dediği 3 dediği hangi kategori bilinmez.

HAVING Komutu

Group By'ın şartıdır

SQL
SELECT müsteriSehir, COUNT(*) FROM Müsteriler GROUP BY müsteriSehir HAVING müsteriSehir != 'Ankara'
-- Ankara hariç diğer şehirleri gruplar ve bunları şehirlere göre gösterir.

Umut'un notu: Şöyle bir benzetme yaptım kendimce; GROUP BY'dan sonra gelen kısım sanki backend yazılımcısıymış gibi bir şey, zira arkada o kategorileri ayıran kişi o aslında. Sadece ekrana getirmiyor. Bunu ekrana getiren "Frontendci" yani SELECT'ten sonra gelen. Onu yazmasaydık ekranda sadece ayrılan kategori sayılarını görürdük.

06

Matematiksel Operatörler

SUM Komutu

SQL
SELECT SUM (ürünStok) FROM Ürünler
-- Ürün tablosundaki ürünlerin toplam stok adedini bulur.

SELECT SUM (ürünStok) FROM Ürünler WHERE ürünFiyat> 20
-- Ürün fiyatı 20'den büyük olanların toplam stok adedini yazdırır.

SELECT ürünAdi, SUM (ürünFiyat * ürünStok)  AS 'TOPLAM' FROM Ürünler GROUP BY ürünAdi
-- Ürünlerin toplam fiyatını TOPLAM sütunu altında tutar.

SELECT ürünKategori , SUM (ürünStok) FROM Ürünler GROUP BY ürünKategori
-- Ürünleri kategorilere ayırıp bunların toplam stok miktarlarını bulur

SELECT SUM(ürünStok) AS 'Toplam Silgi, Dosya, Makas' FROM Ürünler WHERE ürünAdı IN ('Makas' , 'Silgi' , 'Dosya')
-- Ürün adları makas, silgi ve dosya olanların toplam stok adedini verir.

MAX - MİN Komutu

SQL
SELECT MAX (kitapFiyat) FROM Kitaplar
-- Kitapların fiyatından en büyük olanı getirir.

SELECT MİN (ürünFiyat) FROM Ürünler WHERE ürünKategori = 'Kalem'
-- Kategorisi kalem olanlardan en düşük fiyatlı olanı getirir

SELECT MAX (ürünFiyat) AS 'En Yüksek Fiyat ' , MİN (ürünFiyat) AS 'En Düşük Fiyat' FROM Ürünler
-- Ürünler tablosundaki en yüksek satış fiyatı ile  en düşük satış fiyatını listeler

AVG Komutu

SQL
SELECT AVG (ürünStok) FROM Ürünler
-- Toplam stok miktarının ortalamasını alır.

SELECT * FROM Ürünler WHERE ürünFiyat > ( SELECT AVG (ürünFiyat) FROM Ürünler )
-- Fiyatları, ürünlerin fiyat ortalamasından büyük olan ürünleri yazdırır.

SQL

SQL

UPDATE Ürünler SET ürünStok += 25 WHERE ürünStok = (SELECT MIN(ürünStok) FROM Ürünler)

08

Metinsel Fonksiyonlar

Ascii Komutu: Girilen komutun ASCI kod karşılığını verir.

SQL
SELECT ASCII ('A')
-- 65 çıktısını verir

SQLite'ta bu fonksiyonun karşılığı UNICODE()'dur, ASCII() değil — sonuç aynı: 65.

Char Komutu: Girilen ASCI koduna karşılık gelen harfi veren sorgu.

SQL
SELECT CHAR (65)
-- A harfini verir.

Charindex Komutu

SQL
SELECT CHARINDEX ('merhaba', 'hello merhaba dünya')
-- merhaba kelimesinin kaçıncı indexten başladığını gösterir. Bu komutta 7.indexten başlar.

SQLite karşılığı INSTR(metin, aranan)'dır — CHARINDEX'in parametre sırası ters (SQL Server: aranan, metin).

Left Komutu

SQL
SELECT LEFT('Merhaba Dünya',3)
-- Soldan 3 indexi alır. Çıktısı Mer olur

SQLite'ta LEFT() yok, aynı iş SUBSTR(metin, 1, uzunluk) ile yapılır.

Length Komutu: Kaç karakter olduğu bilgisini verir.

SQL
SELECT LEN ('Merhaba Dünya')
-- Kaç karakter olduğu bilgisini verir. Çıktısı 13 olur

SELECT LEN (urunAdi) FROM tbl_urunler

SQLite'ta bu fonksiyon LENGTH() ismiyle çalışır, LEN() değil.

Upper - Lower Komutu

SQL
SELECT UPPER (urun_adi) FROM tbl_urunler
-- Ürünler tablosundaki ürün adlarını büyük harfe çevirir

SELECT LOWER (urun_adi) FROM tbl_urunler
-- Ürünler tablosundaki ürün adlarını küçük harfe çevirir.

Replicate Komutu

SQLSQL Server (T-SQL)
SELECT REPLICATE (urun_adi,2) FROM tbl_urunler
-- Ürünler tablosundaki ürün adlarını 2 defa yazdırır

SQLite'ta hazır REPLICATE fonksiyonu yoktur, benzer sonuç urun_adi || urun_adi ile (metni kendisiyle birleştirerek) elde edilebilir.

Ltrim - Rtrim Komutu

SQL
SELECT LTRİM (ad) FROM tbl_personeller
-- Soldaki boşlukları siler

SELECT RTRİM (ad) FROM tbl_personeller
-- Sağdaki boşlukları siler.

Reverse Komutu: Adları tersten yazar.

SQLSQL Server (T-SQL)
SELECT REVERSE (ad) FROM tbl_personeller
-- Adları tersten yazar.

SQLite'ın çekirdeğinde hazır REVERSE() fonksiyonu yoktur (bir uzantı yüklenmeden çalışmaz).

Substring Komutu: Belli bir kısmı alır. İndex SQL'de 1'den başlar.

SQL
SELECT SUBSTRING ('Merhaba',başlangıç,uzunluk)
SELECT SUBSTRING ('Merhaba',3,5)
-- Belli bir kısmı alır. İndex sqlde 1 den başlar. Çıktısı: rhaba  3.indexle başlayıp 5 karakter sayılır 3.index dahil

SQLite'ta bu fonksiyon SUBSTR() ismiyle çalışır, kullanım mantığı birebir aynı.

09

Aritmetik Fonksiyonlar

Power Komutu: 4'ün 2 üssünü alır.

SQL
SELECT Power (4,2)
-- 4' ün 2 üssünü alır.

Modern SQLite sürümleri matematik fonksiyonlarını destekler; tarayıcın desteklemiyorsa hata alabilirsin, bu durumda not olarak kalması yeterli.

Sqrt Komutu: Çıktısı 9.

SQL
SELECT Sqrt (81)
-- Çıktısı 9

Square Komutu: Çıktısı 625.

SQLSQL Server (T-SQL)
Select Square (25)
-- Çıktısı 625

SQLite'ta doğrudan SQUARE() yoktur; aynı işlem SELECT 25 * 25; ya da POWER(25,2) ile yapılır.

10

Tarihsel Fonksiyonlar

Getdate Komutu: Sorgunun çalıştırıldığı tarih saat bilgisini verir.

SQL
SELECT GETDATE() AS 'Tarih-Saat'
-- Sorgunun çalıştırıldığı tarih saat bilgisini verir.

SQLite karşılığı DATETIME('now')'dur.

DatePart Komutu: Sorgunun çalıştırıldığı tarih bilgisini gün ay yıl olarak parça parça verir.

SQL
SELECT DATEPART (Year, GetDate())
SELECT DATEPART (Month, GetDate())
SELECT DATEPART (Day, GetDate()) AS Gün

SQLite'ta parça parça tarih almak için STRFTIME('%Y'/'%m'/'%d', tarih) kullanılır.

DateAdd Komutu: İstenen tarih veya saat aralığına ekleme yapmak için kullanılır.

SQL
SELECT DATEADD (Day, 5 , GetDate())
-- Bugün Gün 18 ise 25 yapar
SELECT DATEADD (Year, 34 , '08.23.1990') AS 'Yeni Tarih'
-- 08.23.1990 tarihine 34 yıl ekler

SQLite'ta DATE(tarih, '+N days'/'+N years') kalıbı kullanılır.

DateDiff Komutu

SQL
SELECT DateDiff (Day,'09.30.1960','12.30.2024') AS 'Gün Farkı'
-- İki tarih arasındaki gün farkını bulur.

SELECT DateDiff (Month,'09.30.1960','12.30.2024') AS 'Ay Farkı'
-- İki tarih arasındaki ay farkını bulur.

SQLite'ta gün farkı için JULIANDAY() farkı kullanılır; ay/yıl farkı için STRFTIME ile ayrıca hesaplama gerekir.

Ek Örnek

SQL
SELECT * FROM tbl_personeller WHERE YEAR (ise_baslama_tarihi) > 2021
-- Personellerden 2021 sonrasında işe başlayanları gösterir.
SELECT * FROM tbl_personeller WHERE ise_baslama_tarihi BETWEEN '2021' AND '2024'
-- Personellerden 2022 ve 2024 tarihleri arasında işe başlayanları gösterir.

SQLite'ta YEAR() fonksiyonu yoktur, STRFTIME('%Y', tarih) ile yıl çekilir.

11

Birleştirmeler

Beş tür birleştirme: Inner Join · Left Join · Right Join · Full Outer Join · T-SQL

Inner Join

İki tablodaki ortak alanları birleştirmede kullanılır

SQL
SELECT * FROM tbl_personeller INNER JOIN tbl_departman ON tbl_personeller.departman_id = tbl_departman.departman_id
--Personeller tablosu ile departman tablosunu birleştir. Birleştirirken, departman_id'si aynı olan kayıtları eşleştirerek birleştir.

SELECT ad, tbl_departman.departman_id FROM tbl_personeller INNER JOIN tbl_departman ON tbl_personeller.departman_id = tbl_departman.departman_id
-- Üstteki örneğin sadece ad ve departman id kısımlarını getiren halidir. Departman ID iki yerde olduğundan konum belirtilmelidir.

Left Join

SQL
SELECT * FROM tbl_personeller LEFT JOIN tbl_departman ON tbl_personeller.departman_id = tbl_departman.departman_id
-- Soldaki tablonun tamamı, sağdaki tablodan sadece eşleşenler gelir

ad	departman_adi
Ali	     IT
Ayşe	 Muhasebe
Mehmet	 NULL

Playground'daki Personeller tablosunda "Deniz Aksoy" isimli personelin departman_id'si boş (NULL) — Left Join çalıştığında bu satırda departman_adi'nin NULL geldiğini görebilirsin, tıpkı örnekteki "Mehmet — NULL" gibi.

Right Join

SQL
SELECT * FROM tbl_personeller RIGHT JOIN tbl_departman ON tbl_personeller.departman_id = tbl_departman.departman_id
-- Sağdaki tablonun tamamı, soldaki tablodan sadece eşleşenler gelir

ad	departman_adi
Ali	     IT
Ayşe     Muhasebe
NULL	 İnsan Kaynaklar

RIGHT JOIN, SQLite'ın yalnızca yeni sürümlerinde (3.39+) desteklenir. Tarayıcın eski bir sürüm kullanıyorsa hata alabilirsin — bu durumda LEFT JOIN'i tablo sırasını değiştirerek de aynı sonucu elde edebilirsin.

Full Outer Join

Hem sağdaki hem soldaki tabloya göre birleştirme yapar.

SQL
SELECT * FROM tbl_personeller
FULL OUTER JOIN tbl_departman
ON tbl_personeller.departman_id = tbl_departman.departman_id

ad	     departman_adi
Ali	     IT
Ayşe	 Muhasebe
Mehmet	 NULL
NULL	 İnsan Kaynakları

FULL OUTER JOIN da SQLite'ın yeni sürümlerinde (3.39+) desteklenir; playground bunu destekliyorsa doğrudan çalışır.

12

T-SQL

Bu ünitedeki tüm komutlar SQL Server'a özgüdür (T-SQL). DECLARE, SET, PRINT, IF/WHILE gibi programlama yapıları SQLite'ta desteklenmez, bu yüzden bu bölümde çalıştır butonu yok. İçerik yine de birebir korunmuştur.

Değişken tanımlamak için DECLARE komutu kullanırız. Ad isminde bir değişken oluşturup atama yapılıyor ve sonra çağrılıyor.

SQLSQL Server (T-SQL)
DECLARE @ad varchar(20)

Fonksiyonlar (User-Defined)

Fonksiyonlar değer döndürür (RETURN) ve SELECT sorguları içerisinde kullanılabilirler.

SQLite, düz SQL ile kullanıcı tanımlı fonksiyon (CREATE FUNCTION) oluşturmayı desteklemez. Bu ünite SQL Server'a özgüdür.

Örnek 1: Stok değerine 20 ekleyen fonksiyon

SQLSQL Server (T-SQL)
CREATE FUNCTION StokArtir (@stok INT)
RETURNS INT
AS
BEGIN
    RETURN @stok + 20;
END;
SELECT urun_adi, stok_miktari, dbo.StokArtir(stok_miktari) FROM tbl_urunler;

Aynı sonucu playground'da düz SQL ile şöyle alabilirsin:

SQL
SELECT urun_adi, stok_miktari, stok_miktari + 20 AS Artirilmis_Stok FROM Urunler;

Örnek 2: Çalışma süresi hesaplayan fonksiyon (DateDiff)

SQLSQL Server (T-SQL)
CREATE FUNCTION CalismaSuresi (@iseBaslama DATE)
RETURNS INT
AS
BEGIN
    RETURN DATEDIFF(YEAR, @iseBaslama, GETDATE());
END;
SELECT ad, soyad, ise_baslama_tarihi, dbo.CalismaSuresi(ise_baslama_tarihi) AS CalismaYili FROM tbl_personeller;

SQLite karşılığı:

SQL
SELECT ad, soyad, ise_baslama_tarihi,
       CAST((JULIANDAY('now') - JULIANDAY(ise_baslama_tarihi)) / 365 AS INTEGER) AS CalismaYili
FROM Personeller;

Trigger (Tetikleyiciler)

INSERT, UPDATE, DELETE işlemlerinden sonra otomatik çalışan kod bloklarıdır.

İyi haber: SQLite kendi CREATE TRIGGER sözdizimini destekler — ama SQL Server'daki gibi SELECT 'mesaj' veya PRINT ile ekrana yazı basamaz. Bu yüzden orijinal örnekler T-SQL etiketiyle duruyor; altlarına SQLite'ta gerçekten çalışan bir uyarlama ekledim (bir "log" tablosuna yazan trigger).

Uygulama Örnekleri

1. Insert Trigger: Ürün eklenince mesaj ver

SQLSQL Server (T-SQL)
CREATE TRIGGER Urunekle
ON tbl_urunler
AFTER INSERT
AS
BEGIN
    SELECT 'Yeni bir ürün eklendi';
END;
INSERT INTO tbl_urunler values ('Dolma Kalem' , 'Kırtasiye' , 10,12.3)

SQLite'ta çalışan uyarlaması — eklenen her ürünü bir Log tablosuna kaydeder:

SQL
CREATE TABLE IF NOT EXISTS UrunLog (mesaj TEXT);

CREATE TRIGGER IF NOT EXISTS Urunekle
AFTER INSERT ON Urunler
BEGIN
    INSERT INTO UrunLog VALUES ('Yeni bir ürün eklendi: ' || NEW.urun_adi);
END;

INSERT INTO Urunler(urun_adi, kategori, stok_miktari, birim_fiyat) VALUES ('Dolma Kalem','Kırtasiye',10,12.3);
SELECT * FROM UrunLog;

2. Insert Trigger: Toplam stok miktarını göster

SQLSQL Server (T-SQL)
CREATE TRIGGER Urunekle2
ON tbl_urunler
AFTER INSERT
AS
BEGIN
    SELECT SUM(stok_miktari) FROM tbl_urunler;
END;
INSERT INTO tbl_urunler values ('Hesap Makinesi' , 'Kırtasiye' , 20,12.3)

3. Update Trigger: Güncelleme mesajı

SQLSQL Server (T-SQL)
CREATE TRIGGER GuncellemeBilgisi
ON tbl_urunler
AFTER UPDATE
AS
BEGIN
    SELECT 'Güncelleme işlemi gerçekleşti';
END;
UPDATE tbl_urunler SET birim_fiyat = birim_fiyat - 2 WHERE urun_id = 2

4. Update Trigger: Güncelleme sayacını artır (Başka tabloyu etkiler)

SQLSQL Server (T-SQL)
CREATE TRIGGER GuncellemeKontrol
ON tbl_urunler
AFTER UPDATE
AS
BEGIN
    UPDATE tbl_guncelleme SET sayac = sayac + 1;
END;

5. Delete Trigger: Silme mesajı

SQLSQL Server (T-SQL)
CREATE TRIGGER SilmeKontrol
ON tbl_urunler
AFTER DELETE
AS
BEGIN
    SELECT 'Kayıt tablodan silindi';
END;
DELETE FROM tbl_urunler WHERE urun_adi = 'Keçeli Kalem'

6. Delete Trigger: Sayacı azalt

SQLSQL Server (T-SQL)
CREATE TRIGGER SilmeKontrol2
ON tbl_urunler
AFTER DELETE
AS
BEGIN
    UPDATE tbl_guncelleme SET sayac = sayac - 1;
END;
DELETE FROM tbl_urunler WHERE urun_adi = 'Silgi'
