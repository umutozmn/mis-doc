07

Object-Oriented Programming

  • Kodları nesneler üzerinden düzenlemeyi sağlar
  • Kod tekrarını önler
  • Bir nesne oluşturduğunda nesne, o sınıftaki değişken ve metotları miras alır (sahiplenir).

CLASS Özellikleri

  • Kod tekrarını önlemektedir.
  • Nesne (field) oluşturucudur. Birden çok nesne oluşturulabilir.
KodC#
class Car
{
    public int speed;   // FIELD

    void Drive()
    {
        int x = 10;     // BU field değil, yerel değişken
    }
}
// Burada 1 field vardır (speed)
// Burada 2 değişken vardır (speed , x)

Class Members

  • Field
  • Metod
  • Property
  • Constructor
  • Event

Erişim Belirteçleri

  • public: Tüm sınıflardan erişim sağlanır
  • internal: Sınıfın, metodun, değişkenin aynı proje içinde erişilebilir olmasını sağlar. Classların varsayılan erişim belirtecidir.
  • protected: Koda aynı sınıftan veya o sınıftan miras alınan başka bir sınıftan erişilir
  • private: Sadece ait olduğu sınıf içinden erişilir. Metod, Field (Değişken), Property'nin varsayılan erişim belirtecidir

NOT: protected internal ve private protected kombinasyonları da vardır

NOT: Public > İnternal > Protected > Private

08

Encapsulation

  • Properties (get and set) ile yapılır.
  • Verilere kontrollü erişim sağlar. Hassas verileri kullanıcıdan gizler.
  • Private olan nesnelere erişebilmeyi sağlar. Field private yapılır, Property ile erişilir. Get-Set metodları kullanılır
KodC#
 class Kisi
{
    private string bolum;
    public string Bolum
    {
        get { return bolum; }
        set { bolum = value; } // Bu kısımların içi boş da olsa aynı şeyi ifade eder {get; set;} de olur yani.
    }
}

 class Program
{
    static void Main(string[] args)
    {
        Kisi kisi = new Kisi();
        kisi.Bolum = "Yönetim Bilişim Sistemleri"; // set ile value 'YBS' oldu ve bolum=YBS oldu. 
        Console.WriteLine("Kişinin Bölümü: " + kisi.Bolum); // Yazdırma işleminde get çalışıyor ve return ile bolumu döndürüyor. 
    }
}

ÖNEMLİ: Property'ye değer atarsak set, property'den değer alırsak get çalışır.

09

Inheritance

  • Bir sınıfın başka sınıftan özellik almasıdır. Kod tekrarını azaltır base sınıfta kodlar yazılır ama child sınıflarda tekrar yazmazsın.
  • Sealed (Mühür) anahtar sözcüğü ile miras alınma engellenir.
  • Kodların yeniden kullanılabilirliği için faydalıdır.
KodC#
class Vehicle  // base class (ebeveyn)
{
    public string brand = "Ford";
    public void Honk()
    {
        Console.WriteLine("Tuut, tuut!");
    }
}

class Car : Vehicle  // derived class (çocuk sınıf)
{
    public string modelName = "Mustang";
}

class Program
{
    static void Main(string[] args)
    {
        Car myCar = new Car();
        myCar.Honk();  // base sınıftan gelen metot
        Console.WriteLine(myCar.brand + " " + myCar.modelName);
    }
}
Çıktı
Tuut, tuut!
Ford Mustang

Polimorfizm (Çok Biçimlilik)

  • Birden fazla sınıf kalıtımla birbirine bağlı olduğu durumlarda kullanılır.
  • Miras aldığımız yerdeki metodları farklı şekilde kullanmaktır. Virtual ve Override kavramları ile yapılır.
  • Virtual: "Bu metodun çocuk sınıflar tarafından değiştirilebileceğini söylüyorum."
  • Override: "Bu metod çocuk sınıfta base metodun yerine çalışacak şekilde yeniden yazıldı."

Statik Bağlama

  • Burada Pig ve Dog class Animal classdan miras almış fakat Virtual ve Override anahtarları kullanılmadığından sadece base yani Animal class gövdesi çalışmıştır.
KodC#
class Animal  // Base class (parent) 
{
  public void animalSound() 
  {
    Console.WriteLine("The animal makes a sound");
  }
}

class Pig : Animal  // Derived class (child) 
{
  public void animalSound() 
  {
    Console.WriteLine("The pig says: wee wee");
  }
}

class Dog : Animal  // Derived class (child) 
{
  public void animalSound() 
  {
    Console.WriteLine("The dog says: bow wow");
  }
}

class Program 
{
  static void Main(string[] args) 
  {
    Animal myAnimal = new Animal();  // Create a Animal object
    Animal myPig = new Pig();  // Create a Pig object
    Animal myDog = new Dog();  // Create a Dog object

    myAnimal.animalSound();
    myPig.animalSound();
    myDog.animalSound();
  }
}

11

Abstraction

  • Abstract Sınıf: Temeli oluşturur, kuralları belirler. İşleri child sınıflara bırakır. Abstract sınıf veya İnterface ile sağlanır.
  • Abstract Metod: Sadece metod tanımlaması yapılır. İçeriği child sınıfta yapılır.
  • Abstract sınıfta içi dolu metodlar da olabilir.
KodC#
abstract class Animal 
{
 public abstract void animalSound(); // içi boş metod
 public void sleep()  // içi dolu metod
 {
   Console.WriteLine("Zzz");
 }
}
  • Abstract sınıftan nesne oluşturulmaz. Child sınıfla miras alıp child (override ederek) sınıftan nesne türetilir.
KodC#
abstract class Animal  // Soyut sınıf
{
    public abstract void animalSound();   // Soyut metod 
    public void sleep()    // Normal metod 
    {
        Console.WriteLine("Zzz");
    }
}
class Pig : Animal  // Türemiş sınıf
{
    public override void animalSound()    // Soyut metodun gövdesi burada dolduruluyor
    {
        Console.WriteLine("The pig says: wee wee");
    }
}
class Program
{
    static void Main()
    {
        Pig myPig = new Pig();     // Pig nesnesi oluştur
        myPig.animalSound();       // Soyut metod çalışır
        myPig.sleep();             // Normal metod çalışır
    }
}

Interface (Kalıtım - Miraslama)

  • Abstract sınıflarda metodlar dolu da olabilirdi ama Interface sınıflar tamamen soyuttur, dolu metodlar bulunamaz.
KodC#
interface Animal 
{
  void animalSound(); // interface method (does not have a body)
  void run(); // interface method (does not have a body)
}
  • Üyeleri varsayılan olarak Abstract ve Publictir.
  • Properties ve Metod içerebilir fakat Field içeremez (interface veri depolayamaz)
  • Base class yoktur Sözleşmedir aslında ve sözleşmeden miras alırsın.
  • Nesne oluşturulamadığından child sınıflarla erişilir ama Override kullanılmaz (Çünkü base class yoktur üzerine yaz işlemi yapılmasına gerek yoktur)

Validation (Doğrulama)

  • Şifre girerken mesela harf giremezsin diyelim. Ama harf girmeye başladın yanda verilen o uyarı validationdır. Anlık uyarıdır.
  • E-posta kontrolü yaparken belirli bir kalıba (format) uyup uymadığını kontrol etmek için Regex sınıfına ihtiyacımız var.
KodC#
using System;
using System.Drawing;
using System.Text.RegularExpressions;
using System.Windows.Forms;

namespace WindowsFormsApp2
{
    public partial class Form1 : Form
    {
        public Form1()
        {
            InitializeComponent();

            textBox1.TextChanged += textBox1_TextChanged;
            textBox2.TextChanged += textBox2_TextChanged;
            textBox3.TextChanged += textBox3_TextChanged;
        }

        private void textBox1_TextChanged(object sender, EventArgs e)
        {
            ValidateAd();
        }

        private void textBox2_TextChanged(object sender, EventArgs e)
        {
            ValidateYas();
        }

        private void textBox3_TextChanged(object sender, EventArgs e)
        {
            ValidateEPosta();
        }

        private void button1_Click(object sender, EventArgs e)
        {
            bool adOk = ValidateAd();
            bool yasOk = ValidateYas();
            bool epostaOk = ValidateEPosta();

            if (adOk && yasOk && epostaOk)
            {
                MessageBox.Show("Kayıt başarılı", "Bilgi",
                    MessageBoxButtons.OK, MessageBoxIcon.Information);
            }
            else
            {
                MessageBox.Show("Lütfen hataları düzeltin", "Uyarı",
                    MessageBoxButtons.OK, MessageBoxIcon.Warning);
            }
        }

        // Ortak hata gösterme metodu
        private void SetError(Label lbl, string message)
        {
            lbl.Text = message;
            lbl.ForeColor = Color.Red;
            lbl.Visible = true;
        }

        private void ClearError(Label lbl)
        {
            lbl.Text = "";
            lbl.Visible = false;
        }

        private bool ValidateAd()
        {
            if (string.IsNullOrWhiteSpace(textBox1.Text))
            {
                SetError(lblAdError, "Ad alanı boş bırakılamaz");
                return false;
            }

            if (textBox1.Text.Length < 2)
            {
                SetError(lblAdError, "Ad en az 2 karakter olmalıdır");
                return false;
            }

            ClearError(lblAdError);
            return true;
        }

        private bool ValidateYas()
        {
            if (!int.TryParse(textBox2.Text, out int yas))
            {
                SetError(lblYasError, "Sadece sayısal değer giriniz");
                return false;
            }

            if (yas < 18 || yas > 100)
            {
                SetError(lblYasError, "Yaş 18-100 arasında olmalıdır");
                return false;
            }

            ClearError(lblYasError);
            return true;
        }

        private bool ValidateEPosta()
        {
            if (string.IsNullOrWhiteSpace(textBox3.Text))
            {
                SetError(lblEPostaError, "E-posta boş bırakılamaz");
                return false;
            }

            string eposta = textBox3.Text.Trim();
            string pattern = @"^[^@\s]+@[^@\s]+\.[^@\s]+$";

            if (!Regex.IsMatch(eposta, pattern))
            {
                SetError(lblEPostaError, "Geçerli bir e-posta giriniz");
                return false;
            }

            ClearError(lblEPostaError);
            return true;
        }
    }
}
